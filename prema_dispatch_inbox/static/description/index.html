Dispatch Inbox

An email command center for the dispatcher inside Odoo. Fetched inbound email lands in threaded conversations with AI-extracted shipment detail, deterministic corridor pricing, quoted-price controls, draft replies and one-click booking creation — plus Gmail-style compose, Trash/Sent folders and a read-only full-thread compose window. Server-side mail is never altered by this module: no IMAP, fetchmail or SMTP calls exist here.
